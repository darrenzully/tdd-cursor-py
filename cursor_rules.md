# Cursor Rules – TDD First (Python)

## Reglas
- No escribir código de producción sin un test previo
- Implementar solo lo necesario para pasar el test
- Refactorizar solo con tests pasando

## Flujo
RED → GREEN → REFACTOR

## Prompts base
- "Escribí solo el test para este comportamiento"
- "Implementá únicamente el código mínimo"
- "Refactorizá sin cambiar comportamiento"
